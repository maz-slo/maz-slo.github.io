# Shuyi's Portfolio

Personal portfolio website for Shuyi — projects, experience, and writing, built as a fast, static site.

## Tech Stack

- [Astro 5](https://astro.build) (static site generation)
- [React 19](https://react.dev) + [Framer Motion](https://www.framer.com/motion/) (interactive components and animations)
- [Tailwind CSS v3](https://tailwindcss.com)
- [Nanostores](https://github.com/nanostores/nanostores) (state management)
- [lucide-react](https://lucide.dev) icons, self-hosted Inter / Plus Jakarta Sans fonts

## Live Site

Deployed to GitHub Pages at [https://maz-slo.github.io/shuyi.github.io/](https://maz-slo.github.io/shuyi.github.io/).

## Commands

| Command          | Action                                            |
| :--------------- | :------------------------------------------------ |
| `npm install`    | Install dependencies                             |
| `npm run dev`    | Start local dev server at `localhost:4321`       |
| `npm run build`  | Build the production site to `./dist/`           |
| `npm run preview`| Preview the production build locally             |

Requires Node.js `>=20` (LTS).
